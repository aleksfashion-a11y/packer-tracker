# Складской учёт — приложение для упаковщиков

Считает сдельную оплату (по товарам) и почасовую, суммирует их.

## Что внутри
- `server.js` — сервер на Node.js (Express), хранит данные в файле `data/data.json`
- `public/index.html` — интерфейс (открывается в браузере)
- `package.json` — список зависимостей

## Как развернуть на Timeweb App Platform

1. Зайдите в Timeweb Cloud → **App Platform** → «Создать приложение».
2. Загрузите эту папку целиком (можно через загрузку архива, или сначала залить в свой репозиторий на GitHub и подключить его — оба варианта поддерживаются платформой).
3. При настройке приложения укажите:
   - Тип: **Node.js**
   - Команда запуска: `npm start`
   - Порт: **3000** (или оставьте автоопределение — сервер сам читает переменную `PORT`)
4. Нажмите «Развернуть». Через пару минут платформа выдаст вам ссылку вида
   `https://ваше-приложение.timeweb.app` (или похожую).
5. Откройте эту ссылку на любом телефоне/планшете/компьютере — работать может
   сразу несколько человек одновременно, данные общие.

## Важно: сохранность данных

Данные хранятся в файле `data/data.json` на сервере. При обновлении/пересборке
приложения на некоторых платформах этот файл может сбрасываться, если диск не
подключён как постоянный (persistent volume). При настройке в Timeweb ищите
опцию «постоянное хранилище» / «volume» и подключите его к папке `data/` —
тогда записи не потеряются при перезапуске.

Если такой опции нет или сомневаетесь — напишите мне, я перенесу хранение
в отдельную базу данных (SQLite или PostgreSQL от Timeweb), это надёжнее.
