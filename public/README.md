# Складской учёт — версия 2 (полный перенос макета)

Это обновлённая серверная версия, которая содержит **всю** функциональность из последнего макета: логин/QR-вход, варианты упаковки, штрихкоды, секундомер, объявления, графики, экспорт в Excel/PDF, тему, звук, журнал входов и т.д.

## Что внутри и как это устроено

- `server.js` — сервер на Node.js (Express). Отдаёт готовую страницу и простое key-value хранилище (аналог того, что использовал макет внутри Claude).
- `public/bundle.js` — **уже собранное** приложение (React + графики + Excel), собирать на сервере ничего не нужно.
- `public/index.html` — страница-обёртка, подключает `bundle.js`.
- `src/App.jsx`, `src/entry.jsx` — исходный код (на случай, если понадобится что-то поправить и пересобрать заново, см. ниже).

### Где хранятся данные

- Общие данные (сотрудники, записи, цены и т.д.) — на сервере, в файле `data/store.json` (в общем API `/api/kv/...`).
- Личные настройки одного устройства (тема, звук, язык) — в `localStorage` браузера, прямо на устройстве пользователя. Это нормально для отдельного сайта (в отличие от версии внутри Claude, где это было запрещено).

## ⚠️ Важно: то же самое ограничение с диском, что и раньше

Как и в прошлый раз — на данном тарифе Timeweb нет постоянного диска, и `store.json` пишется во временную папку (`os.tmpdir()`). Это значит: **данные всё ещё стираются при каждом обновлении/пересборке приложения**, пока не подключим постоянный диск или базу данных (см. файл истории проекта, раздел про базу данных).

Чтобы не терять данные прямо сейчас — используйте кнопку **«Скачать бэкап (JSON)»** внутри приложения (Настройки → Резервная копия) перед любым обновлением, и «Восстановить из файла» после.

## Как развернуть на Timeweb (App Platform)

1. Загрузите содержимое этой папки в тот же (или новый) репозиторий на GitHub — так же, как в прошлый раз (через «Upload files», предварительно распаковав архив).
   - **Не нужно** загружать папку `node_modules` — её там нет, но если вдруг появится, не грузите.
2. В Timeweb App Platform, в настройках приложения:
   - Тип: **Backend → Node.js → Express**
   - Команда запуска: `npm start`
   - Остальное — как настраивали в прошлый раз.
3. Разверните (или перезапустите деплой, если обновляете существующее приложение).

## Если понадобится что-то поменять в коде дальше

Если Claude (или вы сами) поменяет `src/App.jsx`, файл `public/bundle.js` нужно пересобрать заново. Проще всего — попросить Claude сделать это и прислать обновлённый архив, пересборка происходит автоматически перед выдачей файла.
